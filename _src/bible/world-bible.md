# 《原》世界观圣经

## 一、表层：论坛
- 站点定位：老式文字论坛，气质接近千禧年前后的"真实经历/都市传说/未解案件"版（天涯莲蓬鬼话、猫扑鬼话一类）。
- 暂定站名：**子夜谈**（可后续再改，不影响内容创作）。
- 版面划分（不同版面对应不同帖型，增加论坛真实感）：
  - 民俗怪谈版 → 独白/手记体，长句雕琢，一镜到底
  - 真实案件讨论版 → 楼主分析 + 多人跟帖，跟帖保留论坛原生短促节奏，与正文长句形成对照
  - 情感树洞版 → 私密第一人称告解体
  - 寻人启事版 → 简短寻人帖 + 零散目击回复，信息碎片化
  - 职场吐槽版 → 表面吐槽职场PUA，实则描述组织内部运作
- 底层真相：所有帖子分散在不同版面、不同年代、不同ID之间，看似互不相干，实则全部指向同一个跨越约六十年的组织"原"，与它背后那个没有实体的超自然力量"回响"。

## 二、组织"原"
- 表皮：以"情绪疗愈工作坊""读书会""正念训练营""原生家庭疗愈课"等自我提升话术为外壳，采用真实存在过的心理操控手法（参考人民圣殿教/NXIVM/全能神等真实案例中被验证的手段）：
  - 情感轰炸（love bombing）：新人第一次落泪就被高强度拥抱和"看见"
  - 温水煮青蛙式的逐步索取：从"来听一次课"到"搬进来同住"
  - 信息隔离与外部世界污名化：反复暗示家人朋友"不懂你"
  - 坦白会 + 秘密作为后续要挟的筹码
  - 语言符号重塑：一套只有内部人懂的黑话，用来替换日常情绪词汇
- 更名史（因数次事件败露反复改名重开，黑话与仪式核心不变，只换招牌）：
  1. 本源（1970s，工业城市互助会形式起家）
  2. 回声之家（1990s，购置固定宅邸作为线下据点）
  3. 光合训练营（2000s末，因学员死亡上过地方新闻后转型）
  4. 原（2010s末至今，极度精简、线上化招募，当代帖子多发生在此阶段）
- 内部黑话/层级（跨年代通用）：
  - 外圈学员：**在场者**
  - 一对一发展维系学员的角色：**引路人**
  - 知情组织与"回响"关系的核心层：**记账人**
  - 历史上不止一人担任、自称能与"回响"对话的头衔（非固定个人）：**执灯人**
- 入会核心仪式——**过账**：被吸纳入内圈者在某次坦白会高潮时刻，被要求交出一样绝对私人、无法索回的东西——不是财物，而是一段记忆、一个从未告诉过任何人的秘密、一个只属于自己的声音或名字。完成"过账"后，此人才真正被"回响"记在册上，从此背叛组织即是欠下"回响"的债。

## 三、"回响"
- 没有实体，不显形，无法被召唤来加害外人，**只在"过账"者背叛组织后才会"结账"**——组织自己也无法指挥它何时、以何种方式动手，高层对它抱有真实的恐惧，这不是话术恐吓，是确实存在的力量（文本中不留"到底是不是真的"的暧昧，读者必须能确认它是真的）。
- 结账方式：受害者骨骼在体内被缓慢拧碎、重新排列，皮肤完好无损，无外部创口，现场常见"门窗反锁"等不可能犯罪特征。历年案发地警方多归类为意外死亡/罕见疾病。
- 执行周期不定，"背叛后三十天内"是历史记录里最常见的窗口，但也有拖延数年才结账的个例——这种不确定性本身就是"原"用来维系恐惧的核心工具。
- **关键规则（全文必须保持一致）**：回响从不伤害"在场者"（普通学员）或与组织无关的外人，只精准结算完成过"过账"、级别在记账人以上又选择背叛的人；它不谈判、不提前警告、不接受任何形式的求饶或补偿；结账永远精准指向那个人本身，从不殃及家人——组织拿这一点当"安全承诺"招募人心，而这恰恰更恐怖，因为意味着惩罚永远无法通过牺牲别人来转嫁。
- 起源神话（组织内部流传、真假莫辨）：更早以前，某个封闭乡村社群相信生育与死亡互为债务，每逢入冬会举行"归环"仪式——怀抱夭折或未出生的孩子，围绕一块形似子宫的巨石起舞，将"出生"当作一桩可撤销的错误献还给大地。"原"的创始者发现并拆解了这个仪式，抽走宗教外壳，只留下最核心的东西：一种可以被反复兑现的、生与死之间的债务契约——这就是"过账"与"回响"的雏形。
- "回响"留下的其他痕迹（早于"原"系统化利用它，或独立于"原"的野生显现）：
  - 某街区万圣节出现的黑袍兽首人形，牵引孩子的手作为一种更原始的"献祭中介"，不属于"原"，是创始者认定的"野生变体"，收编未遂
  - 某栋房子里的滑梯与走廊，被某一代记账人买下改造成固定的"过账"场所，使用逾十年后易主
  - 某地猎户世代相传的禁忌：被回响选中的猎物额间会浮现暗红十字，猎杀它等同主动"过账"——这是回响已知最古老的运作方式，比"原"的成立早至少两代人

## 四、时间线（约六十年跨度，供各帖背景挂靠）
1. 1960s末 —— 乡村"归环"仪式最后一次完整记录
2. 1970s —— 创始者拆解仪式，"本源"以互助会形式成立
3. 1980s —— "本源"扩张期，黑袍万圣节事件所在年代与街区（野生变体，与组织若即若离）
4. 1990s —— "回声之家"时期，滑梯宅邸投入使用；同期出现一名被边缘化培养、却自行发展出扭曲收藏欲的"未完成的记账人"
5. 2000s初 —— 猎人与鹿传说被证实与"回响"同源，组织溯源接触该猎户世系失败
6. 2000s末～2010s —— "光合训练营"因学员死亡登上地方新闻，组织第三次更名转入地下网络招募，"骨相案"系列凶案即发生在此阶段
7. 2010s末至今 —— 以"原"为名，几乎完全线上化，经"情绪释放工作坊"招募；论坛里绝大多数当代帖子发生在此阶段
8. "现在" —— 论坛本身。有一个贯穿多条帖子跟帖区、尚未现身的神秘账号，实为组织内部仍在职、已开始动摇的一位记账人，将在压轴长帖主动揭露组织全貌并因此"过账"——全书唯一一次完整展示"回响"结账过程，作为高潮。
